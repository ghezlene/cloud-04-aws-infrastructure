# AWS Infrastructure Lab

> Explore the building blocks of cloud infrastructure on Amazon Web Services.

## Overview

This project explores how cloud infrastructure is designed and deployed using AWS.

Instead of learning AWS services independently, the objective is to understand how they work together to host applications and provide secure, scalable infrastructure.

## Learning Objectives

- Understand cloud computing concepts.
- Explore AWS global infrastructure.
- Understand regions and availability zones.
- Learn IAM users, groups, roles, and policies.
- Understand VPC architecture.
- Configure public and private subnets.
- Explore route tables and internet gateways.
- Deploy EC2 instances.
- Configure security groups.
- Explore S3 storage.
- Understand basic load balancing and database architecture.
- Monitor resource usage and costs.

## Architecture Challenge

Design a basic application infrastructure containing:

- A VPC.
- Public and private subnets.
- An application server.
- Appropriate security groups.
- Storage.
- A documented traffic flow.

##

## Cost and Security Rules

- Check resource costs before deployment.
- Use free-tier or low-cost resources when eligible.
- Avoid unnecessary NAT Gateways and load balancers.
- Delete resources after experiments.
- Never commit AWS access keys or credentials.
- Apply least-privilege IAM permissions.
